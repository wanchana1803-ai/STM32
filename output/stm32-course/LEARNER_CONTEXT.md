# ข้อมูลที่ผู้เรียนยืนยัน

- บอร์ด: NUCLEO-F410RB
- MCU: STM32F410RB
- สร้างโปรเจกต์และตั้งค่า: STM32CubeMX
- เขียนโค้ด build และ debug: STM32CubeIDE
- บทปัจจุบัน: เริ่ม Lab01 LED ยังไม่มีผลทดลองที่ผู้เรียนรายงาน
- ใช้ข้อมูลนี้แทนสมมติฐานเดิมในเอกสารที่ระบุว่ายังไม่ทราบบอร์ด/IDE
- พื้นฐาน C และเวลาเรียนจริง: ยังไม่ยืนยัน
